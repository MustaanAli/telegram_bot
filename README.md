# 🤖 Smart Telegram Bot

🚀 A powerful Telegram bot built with Python to automate group engagement, quizzes, and gamified interactions.

---

## 🔥 Features

### 🌞 Daily Automation

* Good Morning messages (8 AM)
* Daily Quiz system (8 PM)
* Birthday wishes 🎂

### 📊 Quiz System

* Daily quiz with scoring
* Leaderboard tracking
* User rank system (`/leaderboard`, `/myquizrank`)

### 🏆 Saturday Battle Mode

* Random quiz questions
* No repetition system
* Live participation
* Top 3 winners 🥇🥈🥉
* Automatic result announcement

### 😔 Mood & Fun System

* Random mood messages
* Cheer-up messages
* Funny roast system 😂

### ⚙️ Admin Controls

* `/schedule` → schedule messages
* `/stop` → pause bot
* `/resume` → resume bot
